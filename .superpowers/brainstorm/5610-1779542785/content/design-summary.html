Architecture — how it's built
One new script file: src/scripts/interactions.ts
All 4 JS-based effects (magnetic, tilt, cursor glow, scroll progress) live in one file. Each interaction uses a data attribute to opt-in — e.g. data-magnetic, data-tilt. The script runs once on DOMContentLoaded and attaches listeners. No framework, no build step — pure DOM events, ~120 lines total.

CSS-only interactions go into global.css
Nav underline reveal, gradient text shimmer, button press ring, mobile menu slide transition, scroll progress bar styles — all pure CSS. Zero JS overhead. Added to the existing animation token system alongside pulse-dot, .organic-dot, etc.

The 9 interactions
1 · CountUp stats
Numbers roll from 0 on scroll-enter. Homepage stats, technology metrics, solutions page numbers.
Swap bare numbers for <CountUp> on 3+ pages
Existing component
2 · Magnetic CTAs
Brand-gradient buttons attract toward cursor up to 8px, spring back on leave with cubic-bezier(0.34, 1.56, 0.64, 1).
data-magnetic on all .brand-gradient buttons
JS mousemove
3 · 3D card tilt
Cards rotate up to 6deg X/Y on hover. Ambient shadow shifts with tilt direction. Returns to flat on mouseleave.
data-tilt on bento cards, feature cards, farm cards
JS perspective
4 · Hero cursor glow
A 300px radial teal glow follows the cursor on the hero section only. Smooth 80ms lag via lerp. Invisible on touch devices.
Absolute div in hero, JS moves via --cx/--cy CSS vars
JS + CSS var
5 · Scroll progress bar
1px fixed bar at page top. Fills teal→olive as user scrolls. Resets on page load. All pages.
Fixed element in SiteLayout + scroll listener
Lightweight JS
6 · Nav underlines
::after pseudo-element on nav links. Width 0→100% on hover via CSS transition. Gradient teal→olive. Retracts on leave.
CSS only — .nav-link class update in Header.astro
CSS only
7 · Gradient shimmer
Hero gradient text plays a single shimmer sweep on page load (2s, then stops). CSS background-position animation on .text-brand-gradient.
@keyframes shimmer added to global.css — one-shot via animation-fill-mode: forwards
CSS only
8 · Mobile menu transition
Menu panel slides in from right (translateX) with backdrop blur. Links stagger in with 40ms delays. Reverse on close.
CSS transition replaces instant show/hide in Header.astro
CSS + minor JS
9 · Button press feedback
All buttons: scale(0.95) + a teal ring flash on :active. 80ms spring-back. Replaces bare active:scale-[0.98] everywhere.
:active ruleset in global.css for .btn, .brand-gradient, pill buttons
CSS only
